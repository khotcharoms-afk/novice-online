# Project Novice — Phase 4

ต้นแบบเกม MMORPG บนเบราว์เซอร์ (มุมมอง top-down 2D) แรงบันดาลใจจาก RO
Phase 1: ผู้เล่นหลายคนเข้าแผนที่เดียวกัน เดินแล้วเห็นกันแบบ real-time และแชทได้

## อัปเดตย่อย — ปิดงาน Phase 4
- ขาย/ทิ้งของมีค่า (ระดับหายากขึ้นไป หรือตีบวกแล้ว) ต้องกดยืนยันก่อน · ปุ่ม "ทิ้ง" (เลือกจำนวนได้) ในการ์ดไอเทม
- ปุ่ม "ย้ายช่อง" ในการ์ดไอเทม (ใช้แทนการลากบนมือถือ/แท็บเล็ต)
- บันทึกทันทีเมื่อ: ได้ของหายากขึ้นไป · ตีบวก · รวมหิน · ซื้อ/ขายของ 500 gold ขึ้นไป
- ปิดเมนูคลิกขวาของเบราว์เซอร์ในเกม · การ์ดไอเทมไม่ทับช่องที่คลิก (ดับเบิลคลิกได้ทุกช่อง)

## อัปเดตย่อย — ระดับไอเทม + ตีบวก
- อุปกรณ์มี 5 ระดับ: ธรรมดา (ขาว) · ดี (เขียว) · หายาก (ฟ้า) · มหากาพย์ (ม่วง) · ตำนาน (ทอง)
  - ร้านขายแค่ธรรมดา · ของดรอปสุ่มระดับ (71.6% / 20% / 7% / 1.2% / 0.2%) · ได้มหากาพย์ขึ้นไปประกาศทั้งเซิร์ฟ
  - ระดับสูง = ค่าพลังพื้นฐาน ×1.1–×1.7 + ค่าพิเศษสุ่ม 1–4 อย่าง (STR/AGI/VIT/INT/DEX/HP/SP/ATK/DEF)
  - ของดรอประดับดีขึ้นไปมีแสงสีบนพื้น · กรอบในกระเป๋าเป็นสีตามระดับ
- ตีบวก +1 ถึง +10 ที่ NPC "ลุงเหล็กกล้า" (ขวาของร้านค้า) — อาวุธได้ ATK, ของที่มี DEF ได้ DEF
  - ใช้ gold + หินตีบวก: ขั้นต้น (+1–+4: 1/2/3/5 ก้อน) · ขั้นกลาง (+5–+7: 2/3/5) · ขั้นสูง (+8–+10: 2/3/5)
  - หินขั้นต้นซื้อที่ร้าน 30g / ดรอปจากมอนทุกตัว · ขั้นกลาง/ขั้นสูงดรอปจากมอนเลเวลสูง · รวมหิน 5 ก้อน → ขั้นสูงขึ้น 1 ก้อนที่ลุงเหล็กกล้า
  - กรอบไอเทมในกระเป๋าเป็นสีตามระดับทุกระดับ (ธรรมดา = เงิน)
  - +1–+3 สำเร็จ 100% · +4 90% · +5 75% · +6 60% · +7 45% · +8 35% · +9 25% · +10 15%
  - ถึง +4 ไม่มีวันลดระดับ · ตั้งแต่ +5 ล้มเหลวลด 1 ระดับ (ของไม่แตก) · ตีได้ +7 ขึ้นไปประกาศทั้งเซิร์ฟ
- ปรับตัวเลขทั้งหมดได้ที่ `server/items.js` (RARITY / REFINE) · แอดมินให้ของพร้อมเลือกระดับและ +ตีบวกได้

## เมนูแอดมิน (`/admin`)
- เปิดที่ `https://novice-online.onrender.com/admin` (หรือกดลิงก์ "เมนูแอดมิน" ในหน้าเลือกตัวละคร — เห็นเฉพาะแอดมิน)
- **ตั้งใครเป็นแอดมิน:** Render → Environment → เพิ่ม `ADMIN_IDS` = ID ที่ใช้ล็อกอินเกม (หลายคนคั่นด้วย , เช่น `sayan,friend1`)
- ภาพรวม: จำนวนคนออนไลน์ มอน ของบนพื้น RAM + ตารางผู้เล่นออนไลน์ (ส่งกลับเมือง / เตะออก)
- ค้นหาบัญชีด้วย ID หรือชื่อตัวละคร: เพิ่ม/ลดช่องตัวละคร · ตั้งรหัสผ่านใหม่ · ระงับบัญชี (แบน)
- แก้ตัวละคร (ออนไลน์มีผลทันที / ออฟไลน์แก้ในฐานข้อมูล): เพิ่ม/ลด gold · ให้ไอเทม · ลบไอเทม · ตั้งเลเวล · รีเซ็ตสเตตัส · ส่งกลับเมือง · ฟื้นเลือด · เตะออก
- คลิกไอเทมในกระเป๋า/ของที่สวม → แก้ระดับความหายาก · ตั้งตีบวก · สุ่มค่าพิเศษใหม่ · ลบ
- ให้/เปลี่ยน/ลบสัตว์เลี้ยง · แท็บ "ข้อมูลเกม" ดูตารางไอเทม ดรอป ระดับ ตีบวก มอนสเตอร์ ทั้งหมด
- ประกาศถึงทุกคน (ป้ายกลางจอ + แชท) · บันทึกการกระทำของแอดมิน (เก็บใน Firestore `adminLogs`)

## อัปเดตย่อย — สัตว์เลี้ยงช่วยเก็บของ
- ซื้อที่ร้านลุงสมปอง: นกกระจอกน้อย (300g, ระยะ 5 ช่อง) · นกขมิ้นน้อย (1,500g, Lv6, 8 ช่อง) · นกฟ้าน้อย (4,000g, Lv12, 12 ช่อง)
- ดับเบิลคลิกในกระเป๋าเพื่อเรียกออกมา → บินตามเรา และบินไปเก็บของที่ดรอปรอบตัวให้ (คนอื่นเห็นสัตว์เลี้ยงของเราด้วย)
- มีสัตว์เลี้ยงแล้ว AUTO ไม่ต้องเดินไปเก็บของเอง ตีมอนต่อได้เลย · เก็บกลับได้ที่ช่องสัตว์เลี้ยงในหน้าตัวละคร
- ปรับระยะ/ความเร็ว/ราคาได้ที่ `server/items.js` (หมวดสัตว์เลี้ยง)

## อัปเดต Phase 4 — กระเป๋า อุปกรณ์ ดรอป ร้านค้า
- กระเป๋า 40 ช่อง (กด **I**) · ไม่มีระบบน้ำหนัก · เงินชื่อ **gold**
- อุปกรณ์ 10 ช่องในหน้าตัวละคร (กด **C**): หมวก หน้า เสื้อ ถุงมือ เครื่องประดับ×2 อาวุธ มือรอง ผ้าคลุม รองเท้า — ของที่สวมเห็นบนตัวละคร (คนอื่นเห็นด้วย) และค่าพลังที่เพิ่มแสดงเป็นสีเขียว
- ดับเบิลคลิก = ใช้/สวม · คลิก = ดูรายละเอียด · ลากวางได้ (กระเป๋า ↔ ช่องอุปกรณ์ ↔ ช่องลัด Q E R F Z X V B)
- มอนดรอปของ + gold (ของเป็นของคนตีมากสุด 10 วินาที, หายใน 60 วินาที) · คลิกของบนพื้นเพื่อเก็บ
- NPC ร้านค้า "ลุงสมปอง" กลางเมือง: ซื้อยา/อุปกรณ์ · ขายของ · ปุ่มขายของดรอปทั้งหมด
- AUTO: เก็บของอัตโนมัติ + กินยาแดงเมื่อ HP ต่ำ (เปิด/ปิดได้ในหน้าตั้งค่า AUTO)
- ตายเสีย EXP 1% · ปรับค่าไอเทม/ราคา/อัตราดรอปได้ที่ `server/items.js`

## อัปเดต — ระบบสเตตัส
- สเตตัส 5 ตัว: **STR** (พลังโจมตี) · **AGI** (ตีเร็ว/หลบ) · **VIT** (HP/ป้องกัน) · **INT** (SP/ฮีล) · **DEX** (แม่นยำ/คริ)
- เริ่ม 1 ทุกค่า + แต้มอิสระ 5, เลเวลอัป +5 แต้ม · ตัวละครเก่าได้แต้มย้อนหลังตามเลเวลอัตโนมัติ
- หน้าสเตตัส: ปุ่ม **C** หรือปุ่ม "สเตตัส" (มีตัวเลขแดงบอกแต้มค้าง) · ปุ่มลงแต้มแนะนำ
- สูตรทั้งหมดอยู่ใน `server/data.js` (`playerStats`) · เลือดมอนโตแบบยกกำลังสองเพื่อไม่ให้เลเวลสูงง่ายเกินไป
- **ข้อมูลสมดุลสำหรับแอดมิน:** `npm run balance` → `docs/balance.md`, `docs/balance.csv`, (`docs/balance.xlsx` แยกชีทต่อสาย)

## อัปเดตย่อย — ระบบนำทาง + AUTO
- **ระบบนำทาง (A*)**: คลิกเดิน / ไล่ตีมอน / AUTO / มอนไล่ตาม จะเดินอ้อมต้นไม้ หิน น้ำ เอง (`server/path.js`)
  ปุ่มทิศทาง WASD ยังเดินตรงเหมือนเดิม
- AUTO นับมอนที่ "จุดเกิด" อยู่ติดขอบวงด้วย → ไม่ยืนรอมอนเดินเข้าวง
- มอนเกิดใหม่เร็วขึ้น 12 → 8 วินาที
- เปิดหน้าตั้งค่า AUTO แล้วเห็นวงตัวอย่างรอบตัวทันที, วงเข้มขึ้น

## อัปเดต Phase 3 — ล็อกอินด้วย ID + บันทึกตัวละคร
- สมัคร / ล็อกอินด้วย **ID + รหัสผ่าน** (ใช้ Firebase Authentication — ID ถูกแปลงเป็นอีเมลภายใน `id@novice-online.game`)
- 1 ID สร้างตัวละครได้ **3 ตัว** (จำนวนช่องเก็บในข้อมูลบัญชี `slots` → ขยายด้วยไอเทมได้ในอนาคต), ชื่อตัวละครห้ามซ้ำทั้งเซิร์ฟเวอร์
- หน้าเลือกตัวละคร: เล่น / สร้าง / ลบ (ต้องพิมพ์ชื่อยืนยัน)
- บันทึกเลเวล EXP HP SP ตำแหน่ง ลง Firestore: ตอนออกเกม, ทุก 1 นาที, ตอนเลเวลอัป, ก่อนเซิร์ฟเวอร์ปิด
- เข้าตัวละครเดียวกันจากอีกหน้าต่าง → หน้าต่างเก่าถูกตัดออก (กันเล่นซ้อน)
- ปุ่ม "ออก" ในกรอบสถานะ → กลับหน้าเลือกตัวละคร
- **ค่าที่ต้องตั้งใน Render (Environment):**
  - `FIREBASE_SERVICE_ACCOUNT` = เนื้อหาไฟล์คีย์ Service Account (JSON ทั้งไฟล์)
  - `FIREBASE_API_KEY` = Web API Key ของโปรเจกต์ Firebase
  - ถ้ายังไม่ตั้ง เกมจะรันใน **โหมดทดสอบ** (ไม่ต้องใช้รหัสผ่าน, ข้อมูลหายเมื่อเซิร์ฟเวอร์รีสตาร์ท)
- Firestore: `accounts/{uid}`, `characters/{charId}`, `names/{ชื่อตัวเล็ก}` — เซิร์ฟเวอร์เป็นคนอ่าน/เขียนเท่านั้น

## อัปเดต Phase 2 — ระบบต่อสู้
- ทุกคนเริ่มเป็น **ชาวบ้าน** — หน้าเข้าเกมเปลี่ยนเป็นสร้างตัวละคร (เพศ สีผิว ทรงผม สีผม)
- มอนสเตอร์ 5 ชนิด เกิดเป็นโซน ยิ่งไกลจากลานกลางยิ่งแรง:
  ก็อบลินป่า Lv.2 → หมาป่าเร่ร่อน Lv.6 → หมูป่าคลั่ง Lv.10 → โครงกระดูกเฝ้าป่า Lv.14 → ออร์คนักรบ Lv.18
  (Lv.10 ขึ้นไปเป็นมอนดุ เดินเข้ามาตีเอง)
- คลิกมอนสเตอร์ = เดินเข้าไปตีอัตโนมัติ, ตัวเลขดาเมจเด้ง (คริติคอล / MISS), หลอดเลือดมอนสเตอร์
- EXP แบ่งตามดาเมจที่ทำ → เลเวลอัป (เลเวลเดียว ไม่มี Job Level), HP/SP เพิ่มตามเลเวล
- ตายแล้วฟื้นที่ลานกลางใน 4 วินาที, HP/SP ฟื้นเองเมื่อไม่ได้สู้
- สกิลชาวบ้าน: [1] ปฐมพยาบาล (ฟื้น HP 25%) · [2] ฟันซ้ำ (ตี 2 ครั้ง) — กดปุ่มเลขหรือคลิกช่องสกิล
- **ปุ่ม AUTO** (มุมขวาล่าง): ตีมอนอัตโนมัติในรัศมีรอบจุดที่เปิด — เลือกเฉพาะมอนที่เลเวลไม่เกินเรา +2, ไม่แย่งมอนที่คนอื่นตีอยู่,
  ใช้สกิลเอง, เลือดน้อยจะพักรอฟื้นก่อน, ปิดเองเมื่อคลิกเดิน/กดปุ่มทิศ หรือตาย (ทำงานที่เซิร์ฟเวอร์ สลับแท็บได้)
  - ปุ่ม ⚙ ข้าง AUTO: ตั้ง **ขอบเขต** (รัศมี 5 / 11 / 17 ช่องรอบจุดที่เปิด หรือ **ทั้งแมพ**) และ **เลือกชนิดมอน** ที่จะตี
    (ไม่เลือก = ตีทุกชนิดที่เลเวลไม่เกินเรา +2) — มีวงสีทองบนพื้นบอกขอบเขต, ค่าที่ตั้งจำไว้ในเครื่อง
- ถึง Lv.20 จะมีข้อความแจ้ง (เควสเปลี่ยนอาชีพมาใน Phase ถัดไป)
- ปรับตัวเลขสมดุลเกม (เลเวล EXP มอนสเตอร์ สกิล) ได้ที่ `server/data.js` ไฟล์เดียว

## อัปเดต Phase 1.5 — งานภาพ + UI
- เปลี่ยนภาพทั้งหมดเป็นงาน pixel art ชุด LPC (ฟรี ต้องให้เครดิต — ดู `CREDITS.md`)
- แผนที่ 80×60 ช่อง: ต้นไม้ 3 แบบ ป่ารอบขอบ บ่อน้ำ หิน พุ่มไม้ ดอกไม้ ถนนดิน
- ต้นไม้บังตัวละครแล้วจะจางลง
- UI: กรอบสถานะ (HP/SP/Base/Job), มินิแมพ (คลิกเพื่อเดินไป), ซูม, แชทแยกแท็บ, ช่องสกิล/ไอเท็ม (ยังว่าง รอ Phase 2–3)

## ระบบที่มีตอนนี้
- เดินได้ 2 แบบ: **คลิก/แตะพื้น** (แบบ RO) หรือ **WASD / ลูกศร**
- เห็นผู้เล่นคนอื่นขยับแบบนุ่มนวล, ชื่อและเลเวลเหนือหัว, จำนวนคนออนไลน์
- แชท (กด Enter) + บอลลูนคำพูดเหนือหัว
- เซิร์ฟเวอร์เป็นตัวคำนวณตำแหน่งจริง (ผู้เล่นส่งแค่ "อยากเดินไปไหน") → กันโกงวาร์ปตั้งแต่แรก

## ขึ้นออนไลน์ (Render — มีแพ็กเกจฟรี)
> Vercel ใช้กับเกมนี้ไม่ได้ เพราะต้องมีเซิร์ฟเวอร์ WebSocket ที่รันค้างไว้ตลอด
