# Project Novice — Phase 2

ต้นแบบเกม MMORPG บนเบราว์เซอร์ (มุมมอง top-down 2D) แรงบันดาลใจจาก RO
Phase 1: ผู้เล่นหลายคนเข้าแผนที่เดียวกัน เดินแล้วเห็นกันแบบ real-time และแชทได้

## อัปเดต Phase 2 — ระบบต่อสู้
- ทุกคนเริ่มเป็น **ชาวบ้าน** — หน้าเข้าเกมเปลี่ยนเป็นสร้างตัวละคร (เพศ สีผิว ทรงผม สีผม)
- มอนสเตอร์ 5 ชนิด เกิดเป็นโซน ยิ่งไกลจากลานกลางยิ่งแรง:
  ก็อบลินป่า Lv.2 → หมาป่าเร่ร่อน Lv.6 → หมูป่าคลั่ง Lv.10 → โครงกระดูกเฝ้าป่า Lv.14 → ออร์คนักรบ Lv.18
  (Lv.10 ขึ้นไปเป็นมอนดุ เดินเข้ามาตีเอง)
- คลิกมอนสเตอร์ = เดินเข้าไปตีอัตโนมัติ, ตัวเลขดาเมจเด้ง (คริติคอล / MISS), หลอดเลือดมอนสเตอร์
- EXP แบ่งตามดาเมจที่ทำ → เลเวลอัป (เลเวลเดียว ไม่มี Job Level), HP/SP เพิ่มตามเลเวล
- ตายแล้วฟื้นที่ลานกลางใน 4 วินาที, HP/SP ฟื้นเองเมื่อไม่ได้สู้
- สกิลชาวบ้าน: [1] ปฐมพยาบาล (ฟื้น HP 25%) · [2] ฟันซ้ำ (ตี 2 ครั้ง) — กดปุ่มเลขหรือคลิกช่องสกิล
- **ปุ่ม AUTO** (มุมขวาล่าง): ตีมอนอัตโนมัติในรัศมีรอบจุดที่เปิด — เลือกเฉพาะมอนที่เลเวลไม่เกินเรา +2, ไม่แย่งมอนที่คนอื่นตีอยู่,
  ใช้สกิลเอง, เลือดน้อยจะพักรอฟื้นก่อน, ปิดเองเมื่อคลิกเดิน/กดปุ่มทิศ หรือตาย (ทำงานที่เซิร์ฟเวอร์ สลับแท็บได้)
  - ปุ่ม ⚙ ข้าง AUTO: ตั้ง **ขอบเขต** (เล็ก 5 ช่อง / กลาง 11 ช่อง / ใหญ่ 17 ช่อง) และ **เลือกชนิดมอน** ที่จะตี
    (ไม่เลือก = ตีทุกชนิดที่เลเวลไม่เกินเรา +2) — มีวงสีทองบนพื้นบอกขอบเขต, ค่าที่ตั้งจำไว้ในเครื่อง
- ถึง Lv.20 จะมีข้อความแจ้ง (เควสเปลี่ยนอาชีพมาใน Phase ถัดไป)
- ปรับตัวเลขสมดุลเกม (เลเวล EXP มอนสเตอร์ สกิล) ได้ที่ `server/data.js` ไฟล์เดียว

## อัปเดต Phase 1.5 — งานภาพ + UI
- เปลี่ยนภาพทั้งหมดเป็นงาน pixel art ชุด LPC (ฟรี ต้องให้เครดิต — ดู `CREDITS.md`)
- แผนที่ 80×60 ช่อง: ต้นไม้ 3 แบบ ป่ารอบขอบ บ่อน้ำ หิน พุ่มไม้ ดอกไม้ ถนนดิน
- ต้นไม้บังตัวละครแล้วจะจางลง
- UI: กรอบสถานะ (HP/SP/Base/Job), มินิแมพ (คลิกเพื่อเดินไป), ซูม, แชทแยกแท็บ, ช่องสกิล/ไอเท็ม (ยังว่าง รอ Phase 2–3)

## ระบบที่มีตอนนี้
- เดินได้ 2 แบบ: **คลิก/แตะพื้น** (แบบ RO) หรือ **WASD / ลูกศร**
- เห็นผู้เล่นคนอื่นขยับแบบนุ่มนวล, ชื่อและเลเวลเหนือหัว, จำนวนคนออนไลน์
- แชท (กด Enter) + บอลลูนคำพูดเหนือหัว
- เซิร์ฟเวอร์เป็นตัวคำนวณตำแหน่งจริง (ผู้เล่นส่งแค่ "อยากเดินไปไหน") → กันโกงวาร์ปตั้งแต่แรก

## โครงสร้างไฟล์
```
server/index.js      เปิดเซิร์ฟเวอร์ + เสิร์ฟหน้าเว็บ
server/WorldRoom.js  ห้องโลกเกม: ผู้เล่น มอนสเตอร์ การต่อสู้ EXP สกิล แชท
server/data.js       ตัวเลขเกมทั้งหมด (เลเวล มอนสเตอร์ สกิล หน้าตาตัวละคร)
server/map.js        สร้างแผนที่
public/index.html    หน้าเว็บ (หน้าเข้าเกม, HUD, กล่องแชท)
public/game.js       ตัวเกมฝั่งผู้เล่น (Phaser 3)
public/style.css     หน้าตา UI
public/assets/       ภาพแผนที่ สิ่งของ, look/ = ชิ้นส่วนตัวละคร, mobs/ = มอนสเตอร์
CREDITS.md           เครดิตศิลปิน — ห้ามลบ
```

## รันในเครื่อง
ต้องมี Node.js 18 ขึ้นไป
```
npm install
npm start
```
เปิด http://localhost:2567 — เปิด 2 แท็บเพื่อทดสอบผู้เล่น 2 คน

## ขึ้นออนไลน์ (Render — มีแพ็กเกจฟรี)
> Vercel ใช้กับเกมนี้ไม่ได้ เพราะต้องมีเซิร์ฟเวอร์ WebSocket ที่รันค้างไว้ตลอด

1. สร้าง repo ใหม่บน GitHub แล้วอัปโหลดไฟล์ทั้งหมด (ยกเว้นโฟลเดอร์ `node_modules`)
2. เข้า render.com → New → **Web Service** → เลือก repo นี้
3. ตั้งค่า: Build Command = `npm install`, Start Command = `npm start`
4. กด Deploy แล้วเปิด URL ที่ได้ ส่งให้เพื่อนเข้าพร้อมกันได้เลย

หมายเหตุ: แพ็กเกจฟรีของ Render จะหลับเมื่อไม่มีคนเข้าสักพัก การเข้าครั้งแรกหลังหลับจะช้าประมาณ 1 นาที
(Railway / Fly.io ใช้ได้เหมือนกัน ตั้งค่าแบบเดียวกัน)
